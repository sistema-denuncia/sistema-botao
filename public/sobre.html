CONHEÇA O PROJETO

Um caminho simples para pedir ajuda

O One Touch é uma interface web criada para facilitar o envio de um alerta de emergência. A proposta é reduzir etapas e encaminhar os dados do acionamento para uma central integrada, quando essa integração estiver configurada e disponível.

Abrir tela de emergência

Como funciona

  1. Abra a tela de emergência. Use o botão de acionamento somente quando precisar de ajuda.
  2. Permita a localização, se desejar. O navegador pode solicitar acesso à localização do dispositivo. Se ela não estiver disponível ou for negada, o sistema ainda tenta enviar o alerta sem coordenadas.
  3. Aguarde a confirmação na tela. O sistema informa se o alerta foi registrado ou se houve uma falha de comunicação. Se aparecer um erro, não considere o alerta enviado.

Quais dados podem ser enviados

No acionamento, a aplicação prepara um identificador do cliente, o tipo e a prioridade do alerta, informações do navegador/dispositivo e, se disponível e autorizada, a localização aproximada do aparelho.

A localização depende das permissões do navegador e da qualidade do sinal. Ela pode estar indisponível ou imprecisa. O identificador do cliente é guardado no armazenamento local do navegador para reconhecer acionamentos posteriores.

Transparência e confiança

O alerta é encaminhado pela aplicação a um serviço central configurado. O recebimento depende de conexão com a internet, da disponibilidade dos servidores e da integração com a central. Uma mensagem de sucesso indica que o serviço integrado aceitou o registro; não garante, por si só, tempo de resposta ou atendimento presencial.

O projeto não deve ser tratado como substituto de serviços oficiais. Em uma emergência, se o alerta não puder ser enviado ou se você precisar de atendimento imediato, ligue diretamente para o serviço de emergência adequado.

Importante sobre esta versão

Nesta versão do projeto, o formulário de login é demonstrativo: ele não valida credenciais nem cria uma sessão de usuário. A tela de emergência também depende de uma central corretamente configurada para encaminhar alertas. Por isso, não use esta versão como único meio de pedir socorro nem insira nela informações que você não queira compartilhar.

Use o One Touch com responsabilidade.
